为什么需要图提取？

做电商运营、设计选款、素材收集时，你一定遇到过这些麻烦：

🔍

图片太分散

详情页里主图、SKU 图、细节图散落在页面各处，右键一张一张存，效率极低。

🚫

不能批量保存

平台限制右键、长按、保存，想要原图必须手动截图或开开发者工具。

🧩

格式不统一

下载下来是 webp、jpg 混杂，后续抠图、排版还要再转一遍格式。

核心功能

⚡️

一键提取

自动扫描页面所有商品图，兼容懒加载、srcset、背景图。

🧹

智能过滤

自动排除图标、logo、占位图、1×1 像素图和过小缩略图。

🖼️

集中预览

新标签页网格展示所有图片，尺寸、序号一目了然。

☑️

自由勾选

支持全选、反选、单张勾选，想要哪张下哪张。

🔄

统一 PNG

jpg、webp 自动通过 canvas 重编码为透明友好的 PNG。

📦

批量下载

一键保存到本地，文件名自动按 001、002 编号。

四步安装，30 秒搞定

  1. 1

    下载插件并解压

    从 GitHub 仓库下载本项目压缩包，解压到一个固定文件夹（不要删除）。

  2. 2

    打开扩展管理页

    在 Chrome 地址栏输入 chrome://extensions 回车。

  3. 3

    开启开发者模式

    点击页面右上角的「开发者模式」开关，把它打开。

  4. 4

    加载已解压扩展

    点击左上角「加载已解压的扩展程序」，选择刚才解压的文件夹即可。

现在就把详情页图片一键收下

安装后打开任意淘宝 / 京东 / 拼多多商品页，右下角即可看到「获取图片」按钮。
